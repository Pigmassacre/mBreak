We are porting the Python + Pygame game "mBreak" in this repository to C using Raylib.
mBreak is a multiplayer Breakout & Pong game. Two players compete against one another, basically playing Pong. 
Each player controls a paddle and can move it up and down within a game area.
Behind each player are columns of blocks. A player wins by destroy all their opponents blocks.
Blocks are destroyed by damaging them. Blocks can be damaged by many things, by primarily they are damaged by being hit by the ball.
Everytime a ball hits a paddle it changes ownership so the ball is "owned" by that paddle.

The C port is located in the subfolder c-port/.
